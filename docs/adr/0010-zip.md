# ADR-0010 — In-house STORE ZIP + CRC32

**Decision:** No external zip lib. STORE-method (no compression) with a CRC32 of each
entry. Blob download with clipboard fallback.

**Why:** Single-file build, small dependency surface. STORE is enough for portfolio
artifacts (already-extracted text + pcap). CRC32 is ~40 lines of TS.

**Consequences:** No compression; size budget is per-file. Parse-back test in M4-T06.
